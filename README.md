# راهنما کامل ابزار :
خب خدمت تمام رفقا اپل بهتون قابلیت های این ابزار رو میگم بعد بهتون میگم چیکار کنید خب قابایت های این ابزار موقعه ای که روی هاست اپلود کردید باید فایل index.php رو مسیر دهی اصلی سایت کنید و زمانی که کاربر روی لینک بزند یک فایل data.json ساخته میشه که هر دفعه که رو لینک کلیک شه و مجوز های لازم رو کاربر بده این فایل هی بروز میشه و اطلاعات جدید جایگذین این فایل میشه و این فایل هم نیازی نیست خودتون بسارید خود ابزار بعد کلیک کاربر و دادن مجوز ها میسازه حالت قابلیت های این ابزار به همینجا تموم نمیشه
توی فایل data.json یک بخشی وجود داره به نام location که دوتا متغیر داره که عدد هایی وجود داره
<br># مثل زیر :
<div dir="ltr">"location": {
        "latitude": 38.6577658,
        "longitude": 73.356778,
        "accuracy": 2000
}</div>
<br>یک همچین چیزی خب اینحا دوتا متغیر داریم که عدد رو به روشونه یعنی latitude و longitude که زمانی که عدد های اینارو کپی کنید و اینجوری بزارید کنار هم
